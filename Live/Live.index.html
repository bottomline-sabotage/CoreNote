But... what is CoreNote ?

CoreNote is an extension to good-old CoreNote, allowing for "fun" educational experiences! Unlike our competitors, it's completely anonymous (at least, to me) and is 100% free (assuming pain and suffering is free of charge, just like the sarcasm).

No Large Server?

Yep! You download the server and run it yourself locally. Then students, peers, and whatever can go do whatever they want. This keeps all private information private and gives you fun admin commands.

CoreNote Integration

All CoreNote sets comes from .corenote files. You cannot create sets here; go to The Creator for that. CoreNote's Creator itself does have some special -only features, but any CoreNote set should work.
