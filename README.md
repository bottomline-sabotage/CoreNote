# CoreNote

CoreNote is a free, front-end-only online flashcard creator and viewer.

CoreNote has some, uh, *innovative* features, too:
- Asset Uploading (images, videos, audio, and whatever else)
- Text formatting
- Bare HTML card content (for those so inclined)
- Segmented Study (master *n* cards, then move onto the next *n* cards)
- Categories
- Star Difficulty Ratings
- Sets are just `.corenote` files
- Inline comments
- Math Formula support (via LaTeX)

## Getting Started

To start, clone the git repository. Then, host that directory via a simple front-end web server. That's pretty much all the set up! You can also go to [this URL](https://corenote.tylerkoberna.com).
